# Opportunity Hub
1. `npm run update`  -> فایل public/scholarships.json ساخته می‌شود
2. `npm run dev`     -> سایت روی localhost اجرا می‌شود
3. لینک‌های واتساپ/تلگرام: در public/index.html بالای بخش <script>
4. منابع خودکار: data/sources.json | بورسیه‌های ثابت: data/manual.json
5. استقرار: پروژه را در GitHub بگذارید، در Vercel/Netlify وصل کنید، پوشهٔ خروجی = public (بدون build)
   GitHub Actions هر ۶ ساعت لیست را آپدیت و commit می‌کند و سایت خودکار دوباره منتشر می‌شود.
